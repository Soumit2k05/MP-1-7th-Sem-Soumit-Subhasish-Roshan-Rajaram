# ⚡ Electric Load Demand Forecasting Using Machine Learning

A machine learning project that predicts hourly electricity load demand using historical power consumption data. The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, machine learning models, and an interactive Streamlit dashboard.

---

## 📌 Project Overview

This project aims to forecast electricity demand using machine learning techniques. By analyzing historical energy consumption data, the model helps improve demand prediction, enabling better energy planning and resource management.

---

## 🚀 Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Linear Regression
- Random Forest Regressor
- Model Evaluation
- Feature Importance Analysis
- Streamlit Dashboard
